Funktion: Paarweise t-test

Die Funktion nimmt zwei Gruppen und berechnet den t-test [A.] sowie Cohens d [B.] (Effektstärke). Auf Basis des Signifikanzwertes und der Effektstärke wird das “Notwendiges N” [C.] (Power Analysis) abgeleitet. Details zu den Funktionen und deren Parameter innerhalb dieser Funktion kann in den R-packages eingesehen werden.

# ---------------------------------------------------------
# Funktion schreiben, die alle Werte (t-Test, d, N) berechnet
# ---------------------------------------------------------
analyze_kim_scale <- function(data, variable_name, label) {
  
  # A. t-Test berechnen
  test <- t.test(data[[variable_name]] ~ data$group, var.equal = TRUE)
  
  # B. Cohen's d berechnen (dynamisch)
  formula_d <- as.formula(paste(variable_name, "~ group"))
  eff_size <- data %>% cohens_d(formula_d, var.equal = TRUE)
  d_value <- abs(eff_size$effsize) # Betrag nehmen (Richtung egal für Power)
  
  # C. Notwendiges N berechnen (Power Analysis) 
  # Wie viele bräuchte man für Signifikanz (alpha=0.05) bei Power=0.80
  # Hinweis: Wenn d sehr klein ist (< 0.01), explodiert die Zahl. Wir mit if abgefangen
  if(d_value > 0.001) {
    power_calc <- pwr.t.test(d = d_value, sig.level = 0.05, power = 0.80, type = "two.sample")
    n_needed <- round(power_calc$n * 2) # *2, da n pro Gruppe berechnet wird
  } else {
    n_needed <- "> 1.000.000"
  }

  # D. Ergebnis lesbar ausgeben
  cat("---------------------------------------------------\n")
  cat("Dimension:", label, "\n")
  cat(sprintf("t(%g) = %.2f; p = %.3f; d = %.3f\n", 
              test$parameter, test$statistic, test$p.value, d_value))
  cat("Notwendiges N (Gesamt) für Signifikanz:", n_needed, "\n")
}

t-test anwenden

Die Funktion ermöglicht es, den gesamten Datensatz in zwei gewünschte Gruppen zu unterteilen und die oben denfinierte Funktion als paarweisen t-tests durchzufühen. T-tests können ausschließlich zwei Gruppen vergleichen.Eine Alternative ist die ANOVA. Der Vergleich zweier Gruppen ist in dieser Arbeit zeilführender.

run_comparison <- function(data_full, group1, group2) {         # Hilfsfunktion, um zwei Gruppen zu vergleichen
  df_subset <- data_full %>% 
    filter(group %in% c(group1, group2))
  
  cat("\n===================================================\n")
  cat("VERGLEICH:", group1, "vs.", group2, "\n")
  cat("===================================================\n")
  
  # t-test Funktion (siehe oben) auf das Subset anwenden
  analyze_kim_scale(df_subset, "kim_interesse", "Interesse/Vergnügen")
  analyze_kim_scale(df_subset, "kim_kompetenz", "Wahrgenommene Kompetenz")
  analyze_kim_scale(df_subset, "kim_wahl", "Wahrgenommene Wahlfreiheit")
  analyze_kim_scale(df_subset, "kim_druck", "Anspannung/Druck")
}
